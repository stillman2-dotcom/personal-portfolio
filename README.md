# personal-portfolio

## Accessibility Improvements

**Color Contrast:** I darkened the purple footer background because the original color did not provide enough contrast with the white text, making it harder to read.
**Image Alt Text:** I added descriptive alt text to my photo.jpg image so people using screen readers can understand what the picture shows.
**Page Title:** I added a descriptive page title so visitors can identify my website when they open it in a browser.
